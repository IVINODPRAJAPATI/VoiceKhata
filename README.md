# VoiceKhata 💼

VoiceKhata is a smart expense management system designed for institutional use. It allows users to record, analyze, and query expenses using natural language, voice input, and automated reporting.

## 🚀 Features

* 🧠 Smart Expense Entry (Natural Language Input)
* 🎙️ Voice Input for Expenses
* 📸 Receipt Upload (OCR)
* 📊 Financial Dashboard & Analytics
* 💬 Chat-based Query System
* 📄 Automated PDF Reports
* 🔐 Role-based Access (Admin, Faculty, Accountant)

## 🛠️ Tech Stack

* Frontend: React (Vite)
* Backend: FastAPI (Python)
* NLP: spaCy, Transformers
* Database: SQLite
* OCR: Tesseract
* Charts: Recharts

## ⚙️ How to Run

### Backend

```bash
cd backend
venv\Scripts\activate
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
